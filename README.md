# 한 소절 · 계이름 연습

`index.html`을 브라우저로 열면 바로 사용할 수 있습니다. 인터넷 연결, 설치, 서버가 필요하지 않습니다.

모바일 화면(너비 600px 이하)에서는 악보를 한 마디씩 두 줄로 표시합니다. 가로 스크롤 없이 음표를 볼 수 있으며, 선택 메뉴와 버튼을 터치하기 쉽게 배치했습니다. 화면 방향을 바꿔도 같은 문제가 유지됩니다.

- 새로운 악보: 선택한 모드와 음역에서 무작위 2마디 생성
- 연습 모드: 계이름 / 박자 / 계이름과 박자 함께
- 박자 연습: 4분음표(딴, 1박), 2분음표(따안, 2박), 온음표(따아아안, 4박)
- 정답에 읽는 법, 음 길이, 1~4박 세기를 마디별로 표시합니다. 음 재생은 포함하지 않습니다.
- 음역: 기초 / 기본 / 확장 / 아래 덧줄(도3~도4) / 위 덧줄(라5~도6) / 위아래 덧줄 집중 / 전체 혼합(도3~도6)
- 정답 보기: 옥타브 번호를 포함한 계이름 표시
- 기본 연습은 박자 모드입니다. 박자 모드에서는 음높이를 시4로 고정합니다. 음역 기본 선택은 위아래 덧줄 집중이며, 계이름을 연습할 때 매번 아래와 위 덧줄 음이 모두 등장합니다.
- 낮은 음과 높은 음의 덧줄을 표시하고 정답에 옥타브 번호를 붙입니다.
- 높은음자리표, 도장조, 4/4박자 2마디. 계이름 전용 모드는 4분음표만 사용합니다.

음정 읽기에 집중하는 예제로, 음 재생이나 음악적 화성 규칙은 포함하지 않습니다.
