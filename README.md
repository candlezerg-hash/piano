- 새로운 악보: 선택한 음역에서 무작위 8음 생성
- 음역: 도4~솔4 / 도4~도5 / 도4~솔5
- 정답 보기: 옥타브 번호를 포함한 계이름 표시
- 높은음자리표, 도장조, 4/4박자, 4분음표 2마디
