# 한 소절 · 계이름 연습

`index.html`을 브라우저로 열면 바로 사용할 수 있습니다. 인터넷 연결, 설치, 서버가 필요하지 않습니다.

모바일 화면(너비 600px 이하)에서는 악보를 한 마디씩 두 줄로 표시합니다. 가로 스크롤 없이 음표를 볼 수 있으며, 선택 메뉴와 버튼을 터치하기 쉽게 배치했습니다. 화면 방향을 바꿔도 같은 문제가 유지됩니다.

- 새로운 악보: 선택한 모드와 음역에서 무작위 2마디 생성
- 연습 모드: 계이름 / 박자 / 계이름과 박자 함께
- 쉼표 연습: “음표 + 쉼표 섞기”(기본) 또는 “음표만”을 선택합니다. 섞기에서는 매 악보에 쉼표가 하나 이상, 소리 내는 음이 두 개 이상 나옵니다.
- 온·2분·4분·8분·16분쉼표와 점4분쉼표를 음 길이에 맞춰 표시합니다. 쉼표 모양 안내를 펼쳐 각 기호를 확인할 수 있습니다.
- 정답의 “[쉼 · 소리 없이]” 구간에서는 발성하지 않고 “(속으로)” 표시된 박을 셉니다. 6/8의 쉼 길이도 큰 박 기준으로 표시합니다.
- 박자표: 2/4, 3/4, 4/4, 6/8. 한 마디의 길이와 악보의 박자표, 정답의 박 세기를 함께 변경합니다.
- 6/8은 점4분음표를 큰 1박으로 하여 두 박으로 느낍니다. 정답에 큰 박 기준 길이와 8분음표 기준 작은 칸을 구분하고 “1 라 리 / 2 라 리”로 표시합니다. 16분음표는 각 작은 칸을 “앤”으로 한 번 더 나눕니다.
- 6/8 기초 모드에는 점4분음표(따아안)와 4분·8분음표가 포함됩니다. 계이름 전용 6/8은 점4분음표 두 개를 사용합니다.
- 박자 연습: 4분음표(딴, 1박), 2분음표(따안, 2박), 온음표(따아아안, 4박)
- 리듬 난이도: 기초 / 8분음표 포함 / 16분음표 포함. 8분은 따(½박), 16분은 뜨(¼박)로 표시합니다. 읽기 소리는 이 페이지의 연습용 약속입니다.
- 점음표 집중: 점2분(3박), 점4분(1½박), 점8분(¾박)을 박자표에 맞춰 출제합니다(길이는 4분음표=1박 기준). 6/8에서는 점4분이 큰 1박, 점8분이 큰 ½박입니다.
- 점음표 설명을 펼쳐 길이 계산과 박 세기 예제를 확인하세요. 쉼표 섞기와 함께 사용하면 점쉼표도 등장하며 소리 내는 점음표를 최소 하나 유지합니다.
- 정답의 박 세기는 8분 단위에서 “1 앤”, 16분 단위에서 “1 이 앤 아”를 사용합니다. 음을 유지하는 구간은 – 로 연결합니다.
- 짧은 음표는 개별 꼬리로 표기합니다(8분 1개, 16분 2개). 모바일 배치를 위해 한 마디의 음표 수를 최대 8개로 제한합니다.
- 정답에 읽는 법, 음 길이, 1~4박 세기를 마디별로 표시합니다. 음 재생은 포함하지 않습니다.
- 음역: 기초 / 기본 / 확장 / 아래 덧줄(도3~도4) / 위 덧줄(라5~도6) / 위아래 덧줄 집중 / 전체 혼합(도3~도6)
- 정답 보기: 옥타브 번호를 포함한 계이름 표시
- 기본 연습은 박자 모드입니다. 박자 모드에서는 음높이를 시4로 고정합니다. 음역 기본 선택은 위아래 덧줄 집중이며, 계이름을 연습할 때 매번 아래와 위 덧줄 음이 모두 등장합니다.
- 낮은 음과 높은 음의 덧줄을 표시하고 정답에 옥타브 번호를 붙입니다.
- 높은음자리표, 도장조, 선택한 박자표의 2마디. 계이름 전용 단순박자 모드는 4분음표만 사용합니다.

음정 읽기에 집중하는 예제로, 음 재생이나 음악적 화성 규칙은 포함하지 않습니다.
